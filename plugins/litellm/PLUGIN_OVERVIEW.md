## Два корпоративных подключения

Выбирайте LiteLLM / Claude Code или LiteLLM / Codex в стандартном списке агентов BB, затем модель своего корпоративного шлюза. Личные подключения остаются рядом.

Каталог загружается с правами вашего virtual key. Поддерживаются явные канонические псевдонимы, отдельные списки моделей и предпочтительные модели для каждого движка.

## Требования

Нужны установленный Claude Code или Codex CLI, доступ к LiteLLM и персональный virtual key. Запросы расходуют корпоративный бюджет. Ключ вводится в скрытом поле настроек плагина и сохраняется в приватном env-файле выбранной машины; локальный прокси bridge подставляет его в запросы к шлюзу. Глобальные настройки CLI не меняются.

Плагин адаптирует нативные bridge BB и требует проверки совместимости при обновлении BB или CLI. Совместимость инструментов зависит от модели. Выбор reasoning effort и подписочные usage-баннеры в этой версии отсутствуют.
