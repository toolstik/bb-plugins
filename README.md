# bb-plugins

Мои плагины для [bb](https://getbb.app) и синхронизация их набора между компьютерами.

| Плагин | Что делает |
| --- | --- |
| `bulk-delete` | Выделение нескольких тредов в сайдбаре и удаление или архивация разом; удаление всех простаивающих дочерних тредов |
| `clean-copy` | Копирование текста из окна bb без цветов темы, фонов и шрифтов |
| `nested-session-count` | Число дочерних сессий рядом со стрелкой раскрытия в сайдбаре |
| `new-chat-personal` | Кнопка и шорткат New thread всегда открывают чат без проекта |
| `obsidian` | Открывает ссылки на заметки Obsidian из чатов в Obsidian |
| `plugin-sync` | Ставит и обновляет плагины из этого репозитория по кнопке в настройках |
| `session-colors` | Цветные метки тредов в сайдбаре и заголовке |
| `statusline` | Строка над композером: заполнение контекста и лимиты провайдера |

## Новый компьютер

Репозиторий одновременно является маркетплейсом bb. Добавь его в Settings → Plugin marketplaces, указав источник `git:github.com/toolstik/bb-plugins@main`, или командой:

```sh
bb marketplace add git:github.com/toolstik/bb-plugins@main
```

После этого все плагины появятся в магазине bb с обычной кнопкой Install. Достаточно поставить оттуда **Plugin Sync** и нажать **Apply** в его настройках. Кнопка ставит остальные плагины из `marketplace.json`, выставляет шорткаты из `sync.json` и обновляет устаревшие плагины. У каждого устаревшего плагина есть и своя кнопка **Update**.

Дальше `plugin-sync` раз в час проверяет репозиторий. Если появились новые плагины, обновления или расходятся шорткаты, в bb один раз всплывает уведомление с кнопками **Apply** и **Later**. Сам он ничего не ставит и не обновляет. Те же действия есть в настройках плагина и в CLI: `bb plugin-sync status`, `bb plugin-sync apply`, `bb plugin-sync update <id>`.

## Что где лежит

- `plugins/<id>/`: исходники плагинов. Имя каталога совпадает с id плагина.
- `marketplace.json`: единственный список плагинов. Его читают и магазин bb, и `plugin-sync`. Свои плагины ставятся из git с отслеживанием `main`. Сюда же можно добавить чужой плагин с его собственным источником, тогда `plugin-sync` будет ставить его на все машины.
- `sync.json`: переопределения шорткатов (`keyboard`).

## Разработка

На машине, где плагин правится, он установлен с локального пути, и `plugin-sync` его не трогает:

```sh
git clone https://github.com/toolstik/bb-plugins.git ~/src/bb-plugins
bb plugin install path:$HOME/src/bb-plugins/plugins/<id>
bb plugin dev ~/src/bb-plugins/plugins/<id>   # пересборка и перезагрузка при сохранении
```

Остальные машины увидят изменения после `git push` в `main`. Для пуша нужна авторизация: `gh auth login` и `gh auth setup-git`.

Новый плагин: положить его в `plugins/<id>/`, добавить запись в `marketplace.json` по образцу соседних, запушить. Удалённый из репозитория плагин с других машин не удаляется. `plugin-sync` покажет его как "no longer listed", а удалить можно через `bb plugin remove <id>`.
